# 📱 TechCare Services App



## 📌 Overview



TechCare Services is a mobile-oriented Progressive Web App (PWA) developed to simplify the process of requesting and managing repair services for electronic devices and home appliances. The application allows users to submit repair requests, track service status, and interact with the system through a user-friendly interface.



---



## 🚀 Features



* 🔐 User Registration and Login

* 🛠 Repair Service Booking

* 📦 Booking Tracking System

* 🧑‍💼 Admin Panel for Status Management

* 🔔 Notifications for updates

* 📱 Mobile-friendly UI (PWA support)

* 🔓 Logout and session management



---



## 🛠️ Technologies Used



* **Frontend:** HTML, CSS, JavaScript

* **Backend:** Flask (Python)

* **Database:** SQLite

* **Environment:** Jupyter Notebook / Anaconda

* **Deployment:** Local server (PWA)

## ▶️ How to Run the Application


1. Install dependencies:


```
pip install flask

```


2. Run the application:


```
python app.py

```


3. Open in browser:


```
http://127.0.0.1:5000

```


---


## 📱 Run on Mobile (PWA)


1. Connect phone and PC to same WiFi

2. Run:


```
ipconfig

```


3. Open in mobile browser:


```
http://<your-ip>:5000

```


4. Add to Home Screen
